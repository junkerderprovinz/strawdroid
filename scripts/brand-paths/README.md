# Brand marks

`docker.txt` and `github.txt` are the path data of the **Docker** and **GitHub**
marks from [Font Awesome Free](https://fontawesome.com) (brands set). The icons
are licensed **CC BY 4.0**; Font Awesome's fonts are OFL and its code MIT,
neither of which is used here.

`<name>.box.txt` is the mark's own viewBox, so the generator can pull marks of
different proportions to one optical size.

Each mark is a trademark of its owner and is used the one way a trademark may
be used without permission: to name the thing it points at. Each button links
to that thing, the marks are unmodified, and nothing here claims endorsement by
or affiliation with Docker, Inc. or GitHub, Inc.
